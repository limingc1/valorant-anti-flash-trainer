# 无畏契约 · 背闪模拟器

`valorant-anti-flash-trainer.html` —— 零依赖的单文件网页游戏，用来练习《无畏契约》（VALORANT）的**背闪 / 躲闪**反应与回靶速度。

**打开就能玩**：双击 HTML 文件，或直接访问 [在线版](https://valorant-anti-flash-trainer.pages.dev/)。

---

## 怎么玩

第一人称视角面朝一道城墙，正中开一道拱门。闪光会从拱门左右两侧随机飞出，飞行轨迹藏在墙后。

- **躲闪**：闪光引爆的瞬间，如果它在你的视野锥内 → 致盲
- **回靶**：躲开后立刻把准星甩回拱门里的红球并点击，越快分越高
- **落点铺满整个拱门区域**：左上、左下、右上、右下、正中都可能爆开，
  所以回靶时别习惯性盯着拱门中间
- **致盲期间出手无效**，必须先把准星转回来再打
- 白屏淡出到基本看清时射击就恢复正常，不会出现「看着能打其实点不动」

命中、被致盲、MISS 都**不会在屏幕中间弹字**，信息只进左下角滚动日志，不挡视野。
屏幕上保留的反馈只有左上角那块连击牌。

## 闪光防护（默认开启）

设置 → 辅助 → **闪光防护**，默认开启，采用「回放里的闪光防护」那种表现：

- 被闪时**画面保持可见**，只叠一层淡白雾，不会整屏全白
- 准星正上方显示一个**白色眼睛图标 + 恢复圆环**，环随致盲恢复逐渐缩短，旁边显示剩余秒数；
  图标固定在屏幕位置，**不跟随鼠标或视角**
- 恢复阶段文案从「致盲中」变为「恢复中」，照着它就知道什么时候能重新开枪

三条边界，改代码时别动：

- **只改变显示，不改变规则**：致盲时长、射击限制（强度阈值）、命中判定与计分完全一致
- **只覆盖白屏类的闪**：普通闪光与盖克电浆
- **蕾娜之眼是近视，不做护眼**：它始终是原来的紫雾 + 靶球被吞掉

想要原版满屏白屏，把它关掉即可；该设置只保存在本机，联机房主和每日挑战都不会覆盖它。

## 靶点

拱门区域里**同时存在多颗红球**（默认 5 颗，可在设置里调 1–9 颗）。

- 打掉一颗 → 那颗立刻在区域内随机位置重生，其余保持不动
- **没有存活时间限制**，球不会自己消失，也就没有倒计时圆环
- 新球有短暂弹入动画，方便你注意到补位发生在哪
- 闪光飞来时靶点不再整片重排（那样回靶手感会失真）
- 球体是**球面光照贴图**：受光面、暗部、集中高光一次烘成位图，看起来是立体的球，
  但仍是一次绘制，不增加运行负担

### 菲尼克斯曲球 · 回头弧

曲球的本质是**可以转弯的弧形投射物**，不是直线穿门。

1. 从掩体后朝拐角**外侧**抛出，先往墙外飞
2. 越过最外点后拐回来，绕着墙角进入门洞
3. 前一半路程藏在墙后 —— 看不见
4. 绕过拐角后**从拱门洞里穿进来**才现身，留给你的反应窗口最短

所以它是所有闪光里**最难读**的一个。撞墙转弯的瞬间会在拐角处炸出一圈火星，
那是唯一的前置提示。拖在球身后那条能量束只画到门洞边缘为止，所以能告诉你球是从哪一侧绕过来的。

### 蕾娜之眼 · 近视 Nearsight

跟其他闪光都不一样，没有飞行轨迹：

1. 紫眼在拱门附近**凭空浮现**，用约 0.5 秒**睁开**（浮现阶段打不掉）
2. 睁开的瞬间，如果它在你的视野锥内且有视线 → 进入**近视**
3. 近视**不是白屏**：屏幕被暗紫笼罩，近处还看得清，**远处被浓雾吞掉**
4. **拱门里的靶球完全看不见**，也打不到 —— 只能先处理紫眼
5. 紫眼**要打两下**才摧毁：第一下只是打裂（留下裂痕、闪白抖动），第二下才碎
6. 击毁后近视立即解除。没打掉它会自行消散作为兜底

被近视笼罩时左上角会显示「近视 · 击毁紫眼解除」。转身背对它同样可以免疫。
**注意：闪光防护不作用于它**，这是一个刻意保留的难度设计。

### 维斯 · 弧玫瑰

1. 液态金属贴到拱门两侧的实墙面上，凝成一颗半透明花蕊
2. **蓄势**：花蕊带呼吸微光，蓄势时长每次都不同（2.5–6 秒）
3. **绽放**：花开始旋转张开，同时播放绽放音效 —— 这就是预警
4. **引爆**：开满后渐亮紫光，随后紫白色爆闪

**蓄势期和绽放期都能打掉**：打掉即终止生成或取消爆闪，绝不会再闪，
并算作一次成功应对。打不掉就得转身背掉。

### 盖克 · 丢丢

1. **飞行**：从拱门边抛出，直线飞到空中（不走弧线，方向一眼能读）
2. **扫描锁定**：出现后约 0.25 秒锁定，红色光膜亮起
3. **前摇发射**：锁定后再约 0.35 秒×难度系数发射电浆（普通难度约 0.60 秒）
4. **命中致盲**：电浆命中后是蓝色遮屏，持续 1.8 秒（末 0.45 秒淡出）

**丢丢无法背闪**：转身对它没用，只有在**发射电浆之前**把它打掉才不会被致盲。
发射前击毁 = 成功应对并加分；发射后击毁不取消已经在飞的独立电浆，也没躲闪分。

## 单轮训练与结算

默认一轮 **60 秒**，可切 30s / 60s / 120s / 不限。倒计时在右上角，最后 10 秒转红。

时间到自动结束并弹出结算面板：总分、背闪率、命中率、最高连击、被闪次数、
转身反应、回靶耗时、命中/出手，并给一句针对本轮数据的点评。
面板里还能直接看到**最近训练与分数走势**，或点「设置」当场调整。可以「再来一轮」或「继续自由练习」。

## 计分

| 项目 | 分值 |
|---|---|
| 命中靶球 | 基础 10 + 回靶速度 0–15 + 精准 0–10 |
| 连击倍率 | 每连击 +4%，15 连封顶 **1.60×** |
| 躲开一次闪光 | 15（连击加成后最高约 21） |
| 打裂蕾娜之眼 | 8 |
| 摧毁蕾娜之眼 | 25 |
| 击毁维斯玫瑰 | 20 |
| 发射前击毁丢丢 | 25 |

单球理论上限 **56 分**，一轮 60 秒打下来总分基本在四位数以内。

### 擦闪宽容

背掉锥角最外一圈算**擦闪**：白屏照旧来一下，但很短、很轻，按**躲闪成功**算 —— 不断连击。

原因是布雷奇的锥角（70°）比屏幕半 FOV（51.5°）还大，那一圈画面上根本没有光点，
却仍按角度判被闪、还断连击，手感像随机挨刀。蕾娜之眼有更宽的一档，贴边瞥到不会断连击。

## 训练记录与每日挑战

- **训练记录**：按「时长 × 难度」保存最佳成绩，另有最近 100 条流水与分数走势图（可切分数 / 背闪率 / 准度）
- **每日挑战**：每天一条全网相同的规则（如「丢丢疯潮」「荆棘玫瑰」「五只眼」），
  同日同种子 = 全网同一串闪光，纯拼操作；每人每天最好成绩上榜

## 联机对战

创建房间 → 把房码或链接发给朋友 → 双方各点「我准备好了」→ 3 秒倒计时**同时开局** →
打完各自交卷，自动判胜负。

- 房码本身携带**时长 + 种子**，两人打的是完全相同的一串闪光
- 云端不可用时自动降级为「同房码离线对战 + 口头比分」，照常能玩
- 比分由各自浏览器自报，属荣誉制，适合朋友间娱乐
- 设置里的**公平项**（特工池 / 难度 / 模式 / 频率 / 靶点数）由房主同步；
  灵敏度、FOV、准星、画质、闪光防护等个人手感与显示设置**不同步**

> 联机依赖 Cloudflare KV，一局固定 6 次写。部署与 KV 绑定见 [`DEPLOY.md`](DEPLOY.md)。

## 音乐盒

内置 7 首曲目（放进 `music/` 文件夹，随仓库入库）。

- **按需加载**：打开训练器时**不读取、不下载、不播放**；
  点开「音乐盒」页签或点播放控制才开始加载，不会白白占带宽
- 播放范围：关闭 / 仅菜单 / **菜单+训练**（默认最后一项）
- 「出手声压低音乐」：闪光出手时把音乐压低，帧内平滑过渡
- 也可以「＋ 添加歌曲」从本机导入，或「重扫 music/」

## 可调项

训练模式（综合 / 躲闪 / 靶场）、**难度曲线**（普通 / 困难）、闪光轨迹可见度（正常 / 短暂 / 无）、
**单轮时长**、自动闪光频率（手动 **0.3×–1.0×**；个别每日挑战规则会开到 1.6×）、
鼠标灵敏度（基于游戏内 0.07°/count）、
FOV（默认 103° 即瓦罗兰特锁定的水平 FOV）、靶点大小、
**同时靶点数**（1–9）、**渲染画质**、准星五样式五颜色四滑杆、
闪光防护、音效、动态模糊、Y 轴反转。

**渲染画质默认「流畅」**，设置里会显示当前实际分辨率（例如「选择 流畅 · 当前 960 × 540 · 0.75×」）：

| 档位 | 像素密度上限 | 说明 |
|---|---|---|
| 流畅（默认） | 0.75 | 最省，低配设备首选 |
| 标准 | 1.0 | 与屏幕同分辨率 |
| 精细 | 2.0 | 允许 2 倍密度；普通屏幕上与标准相同，不是强制超采样 |

实际密度取「设备密度」与「档位上限」的较小值。帧率持续偏低时会自动降档，
面板上会标注「已自动降档」——它只是临时状态，**不会覆盖你选的档位**，再点一次即可恢复。

## 音效

默认用 WebAudio 实时合成，八种闪光各有自己的引爆音色。

想换成游戏原声：把音频文件放进 HTML 同级的 `sfx/` 目录，按 `phoenix_pop.mp3`、
`kayo_beep.wav` 这样的名字命名，刷新页面即可自动替换。详见 [`sfx/README.md`](sfx/README.md)。
设置底部会显示「自定义音效 N 个已载入」还是「使用内置合成音」。

推荐的做法是**录制 + 自动切分**：`sfx/split-recorded.py` 可以按静音把你录的一长段
切成一堆片段，并打印每段的峰值与间隔，帮你分辨「出手」和「引爆」。

`sfx/` 与 `music/` 里的音频会随 git 一起提交，push 后线上也能听到。

## 实现

- 单文件纯前端：`HTML + CSS + 原生 JavaScript`，约 5700 行，无任何外部库；
  除可选的 `sfx/`、`music/` 音频外不发起网络请求
- 伪 3D 软件渲染：自写相机变换 / 近平面裁剪 / 透视投影，Canvas 2D 绘制
- 墙面与拱门：暖沙灰泥墙（前墙另有百叶窗、庭院铭牌、露砖、裂纹等装饰）、
  门洞后红砖廊道、楔形拱石与门柱**共用同一截面与连接边**
- 音效默认 WebAudio 实时合成，检测不到 `sfx/` 文件时不产生额外请求
- 闪光遮挡判定：墙前完全可见；墙后仅当投影落在拱门洞内才可见
- 致盲判定：引爆瞬间视线与闪光方向夹角小于该特工锥角时致盲，夹角越小白屏越久
- 近视效果：直接改渲染的距离雾参数（雾线拉近压浓、雾色转暗紫）＋ 暗紫遮罩，
  所以「远处看不清」是真的由渲染管线产生的，不是盖一层图假装

### 几处容易踩坑的实现细节

- **鼠标输入按帧合并**：`mousemove` 只累积位移，主循环里统一应用一次。
  直接在事件里转相机会导致同一帧多次转动，掉帧时表现为视角瞬移。
  同时丢弃超过 1500 count 的异常位移（驱动尖峰），避免视角突然甩飞。
- **累积值必须有单帧预算**：只合并不设上限会更糟 —— 掉帧时一帧能攒下几十个事件，
  一次性转出上百度，正是「视角突然跳走 / 被拉回正」的成因。
  现在单帧预算 800 count，并按帧时长放宽最多 3 倍，保证低帧率下也不会吃掉正常甩狙的输入。
- **CSS 滤镜只在值变化时写入**：每帧无条件设置 `canvas.style.filter` 会强制样式重算，
  全屏画布上是掉帧的主因之一。
- **暂停要做时间平移**：全局时钟 `T` 在暂停期间照常推进，而闪光和靶点记的都是绝对时间，
  恢复时必须把这段时长补回所有时间戳，否则飞行中的闪光会瞬间引爆。
- **致盲强度用「起点 + 终点」表示，不用「剩余 / 总时长」**：
  旧写法在第二发闪叠加时把 `blindDur` 重设成剩余时长，于是强度又跳回满值，
  白屏被反复续满、射击长时间只出 MISS 音。现在叠加时只外推结束时刻，强度曲线单调衰减。
- **闪光排期有间隔保护**：任意两次引爆至少隔开 1.2 秒（困难 0.9 秒），
  且新闪光的预警不会落在别人引爆后的恢复窗口里 —— 否则会出现「刚被炸完下一发就贴脸」这种没得反应的连闪。
- **暂停期间不重排闪光**：排期只读固定的账本，不参考玩家是否被闪、有没有打掉玫瑰，
  否则联机两人和每日挑战全网的题目顺序会分叉。
- **拖尾按固定采样率记录**（1/70 秒一个点），点数与帧率无关，高刷屏不会堆出上百个绘制点。
- **渐变改成离屏位图**：靶球、光晕、爆闪的 `createRadialGradient` 一次性预渲染成
  位图缓存，每帧只做 `drawImage`。
- **渲染减负**：不可见的走廊贴片按门洞包围框剔除；视角不动时复用静态房间背景
  （技能、靶球、遮罩仍逐帧绘制）；相机三角函数按视角变化缓存。
  结果：正面场景的图片绘制次数约从 637 降到 357。
- **墙面贴图不能按视角切换方式**：曾经在接近正视时用「整墙两片」、稍一转头改为细分网格，

## 已知限制

- **实时比分**：对战中不轮询云端（省 KV 额度），比分在双方交卷后汇总
- **联机同步**：KV 不是强一致存储，跨地区读延迟下无法保证严格同时开局；
  等待过久可在面板里显式选择「同房码离线开局」，双方口头核对
- **靶点布局**：联机两人各自打掉各自补，靶点位置不保证逐颗一致（异步同种子对战的固有权衡）
- **每日榜单**：本地 `python -m http.server` 没有 Pages Function，榜单会显示「暂时拉不到」，
  这是正常现象；要看真榜单请用部署站点
