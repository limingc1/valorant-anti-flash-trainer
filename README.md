# 无畏契约 · 背闪模拟器

`valorant-anti-flash-trainer.html` —— 零依赖的单文件网页游戏，用来练习《无畏契约》（VALORANT）的**背闪 / 躲闪**反应与回靶速度。

## 怎么玩

第一人称视角面朝一道城墙，正中开一道拱门。闪光会从拱门左右两侧随机飞出，飞行轨迹藏在墙后。

- **躲闪**：闪光引爆的瞬间，如果它在你的视野锥内 → 白屏致盲
- **回靶**：躲开后立刻把准星甩回拱门里的红球并点击，越快分越高
- **致盲中看不见靶点**，此时命中无效 —— 必须先转身再回靶

## 闪光类型

| 特工 | 技能 | 形态 | 特点 |
|---|---|---|---|
| 菲尼克斯 | 曲球 Curveball | 红色火球 | 弧线大、飞行久，最好读 |
| 斯凯 | 飞鸟 Guiding Light | 绿色飞鸟 | 快，引爆时机不固定 |
| 布雷奇 | 闪光点 Flash Point | 墙面单颗黄点 | 墙后引爆，先亮黄点再爆开 |
| 恺 | 闪光驱动 FLASH/drive | 蓝色长方体 | 飞行中有滴答声 |
| 夜露 | 致盲球 Blindside | 紫色光球 | 高抛弹地，飞得久但锥角小 |
| 蕾娜 | 致盲之眼 Leer | 紫色眼球 | 悬停时可击毁，打掉即免盲 |

> 后 3 种默认关闭，在右侧「闪光类型」里点击开启。

## 操作

| 按键 | 功能 |
|---|---|
| 移动鼠标 | 转视角 |
| 左键 / 空格 | 射击 |
| `F` | 手动触发闪光 |
| `R` | 刷新靶点 |
| `A` | 自动闪光开关 |
| `M` | 静音 |
| `Esc` | 暂停 |

## 可调项

训练模式（综合 / 躲闪 / 靶场）、4 档难度曲线、闪光轨迹可见度、自动闪光频率、
鼠标灵敏度（基于游戏内 0.07°/count）、FOV、靶点大小与存活时间、音效、动态模糊、边缘方位提示、Y 轴反转。

## 运行

双击 HTML 文件用浏览器打开即可 —— 无需安装任何依赖，也**不需要联网**。
建议使用 Chrome 或 Edge，全屏（`F11`）体验最佳。

## 实现

- 单文件纯前端：`HTML + CSS + 原生 JavaScript`，约 1400 行，无任何外部库与网络请求
- 伪 3D 软件渲染：自写相机变换 / 近平面裁剪 / 透视投影，Canvas 2D 绘制
- 墙面细节：拱腹、楔形拱石、门框柱、壁柱、横梁、踢脚线与腰线，带明暗与距离雾
- 音效全部由 WebAudio 实时合成
- 闪光遮挡判定：墙前完全可见；墙后仅当投影落在拱门洞内才可见
- 致盲判定：引爆瞬间视线与闪光方向夹角小于该特工锥角时致盲，夹角越小白屏越久
