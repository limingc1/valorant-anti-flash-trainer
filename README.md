# 无畏契约 · 背闪模拟器

`valorant-anti-flash-trainer.html` —— 零依赖的单文件网页游戏，用来练习《无畏契约》（VALORANT）的**背闪 / 躲闪**反应与回靶速度。

## 怎么玩

第一人称视角面朝一道城墙，正中开一道拱门。闪光会从拱门左右两侧随机飞出，飞行轨迹藏在墙后。

- **躲闪**：闪光引爆的瞬间，如果它在你的视野锥内 → 白屏致盲
- **回靶**：躲开后立刻把准星甩回拱门里的红球并点击，越快分越高
- **落点铺满整个拱门区域**：左上、左下、右上、右下、正中都可能爆开，
  所以回靶时别习惯性盯着拱门中间
- **致盲中看不见靶点**，白屏还没退干净时出手判为无效 —— 必须先转身再回靶。
  判定跟着画面走：白屏淡出到基本看清时射击就已经恢复，不会出现"看着能打其实点不动"

命中、被致盲、MISS 都**不会在屏幕中间弹字**，信息只进左下角滚动日志，不挡视野。
屏幕上保留的反馈只有左上角那块连击牌。

## 靶点

拱门区域里**同时存在多颗红球**（默认 5 颗，可在右侧调 1–9 颗）。

- 打掉一颗 → 那颗立刻在区域内随机位置重生，其余保持不动
- **没有存活时间限制**，球不会自己消失，也就没有倒计时圆环
- 新球有短暂弹入动画，方便你注意到补位发生在哪
- 闪光飞来时靶点不再整片重排（那样回靶手感会失真）

## 闪光类型

| 特工 | 技能 | 形态 | 特点 |
|---|---|---|---|
| 菲尼克斯 | 曲球 Curveball | 红色火球 | 弧线大、飞行久，最好读 |
| 斯凯 | 飞鸟 Guiding Light | 绿色飞鸟 | 引爆时机不固定 |
| 布雷奇 | 闪光点 Flash Point | 墙面单颗黄点 | 墙后引爆，先亮黄点再爆开 |
| 恺 | 闪光驱动 FLASH/drive | 蓝色长方体 | 飞行中有滴答声 |
| 夜露 | 致盲球 Blindside | 深蓝色光球 | 高抛弹地，锥角小 |
| 蕾娜 | 致盲之眼 Leer | 紫色眼球 | 凭空浮现后睁开 → **近视**，必须打掉才解除 |

> 后 3 种默认关闭，在右侧「闪光类型」里点击开启。

### 蕾娜之眼 · 近视 Nearsight

跟其他闪光都不一样，没有飞行轨迹：

1. 紫眼在拱门附近**凭空浮现**，用约 0.5 秒**睁开**（浮现阶段打不掉）
2. 睁开的瞬间，如果它在你的视野锥内且有视线 → 进入**近视**状态
3. 近视**不是白屏**：屏幕被暗紫色笼罩，近处还看得清，**远处被浓雾吞掉**
4. **拱门里的靶球会完全看不见**，也打不到 —— 只能先处理紫眼
5. 紫眼**要打两下**才摧毁：第一下只是打裂（留下裂痕、闪白抖动），第二下才碎
6. 击毁后近视立即解除。6 秒内没打掉，它会自行消散作为兜底

被近视笼罩时左上角会显示「近视 · 击毁紫眼解除」。转身背对它同样可以免疫。

## 准星

右侧「准星」区可调：**十字 / 点 / 圆 / T 字 / 无** 五种样式，
五种颜色，以及长度、粗细、中心间隙三个滑块，另可在「辅助」里关掉中心点。

准星直接画在 canvas 上（不是 DOM），每种形状都会先描一圈半透明黑边再上色，
保证在亮墙面、白屏、紫幕上都看得清。

## 单轮训练

默认一轮 **60 秒**，可在右侧切 30s / 60s / 120s / 不限。倒计时在右上角，最后 10 秒转红。

时间到自动结束并弹出结算面板，列出总分、背闪率、命中率、最高连击、被闪次数、
转身反应、回靶耗时、命中/出手，并给一句针对本轮数据的点评。
可以「再来一轮」或「继续自由练习」（后者会切到不限时）。

## 计分

| 项目 | 分值 |
|---|---|
| 命中靶球 | 基础 10 + 回靶速度 0–15 + 精准 0–10 |
| 连击倍率 | 每连击 +4%，15 连封顶 **1.60×** |
| 躲开一次闪光 | 15（连击加成后最高约 21） |
| 打裂蕾娜之眼 | 8 |
| 摧毁蕾娜之眼 | 25 |

单球理论上限 **56 分**，一轮 60 秒打下来总分基本在四位数以内。

## 可调项

训练模式（综合 / 躲闪 / 靶场）、**难度曲线**（普通 / 困难）、闪光轨迹可见度（默认正常）、
**单轮时长**、自动闪光频率（0.3×–1.0×，1.0× 即最快）、鼠标灵敏度（基于游戏内 0.07°/count）、
FOV（默认 103° 即瓦罗兰特锁定的水平 FOV）、靶点大小（0.04–0.15，默认 0.10）、
**同时靶点数**（1–9）、**渲染画质**（流畅 / 标准 / 精细）、
音效、动态模糊、边缘方位提示、Y 轴反转。

觉得卡就先把画质切到「流畅」，右上角有实时 fps —— 帧率持续低于 45 时会自动降一档渲染精度。
按 `H` 可以把右侧数据栏整个收起来，画面更沉浸，数据照常统计。

## 音效

默认用 WebAudio 实时合成，六种闪光各有自己的引爆音色。

想换成游戏原声：把音频文件放进 HTML 同级的 `sfx/` 目录，按 `phoenix_pop.mp3`、
`kayo_beep.wav` 这样的名字命名，刷新页面即可自动替换。详见 [`sfx/README.md`](sfx/README.md)。
侧栏底部会显示当前是「自定义音效 N 个已载入」还是「使用内置合成音」。

推荐的做法是**录制 + 自动切分**（`sfx/split-recorded.py` 可以直接按静音把你录的一长段
切成一堆片段），比解包省事得多。解包那条路要过反作弊，不展开。

## 运行

双击 HTML 文件用浏览器打开即可 —— 无需安装任何依赖，也**不需要联网**。
建议使用 Chrome 或 Edge，全屏（`F11`）体验最佳。

## 实现

- 单文件纯前端：`HTML + CSS + 原生 JavaScript`，约 2030 行，无任何外部库与网络请求
- 伪 3D 软件渲染：自写相机变换 / 近平面裁剪 / 透视投影，Canvas 2D 绘制
- 墙面细节：拱腹、楔形拱石、门框柱、壁柱、横梁、踢脚线与腰线，带明暗与距离雾
- 音效默认 WebAudio 实时合成，检测不到 `sfx/` 文件时不产生任何网络请求
- 闪光遮挡判定：墙前完全可见；墙后仅当投影落在拱门洞内才可见
- 致盲判定：引爆瞬间视线与闪光方向夹角小于该特工锥角时致盲，夹角越小白屏越久
- 近视效果：直接改渲染的距离雾参数（雾线拉近压浓、雾色转暗紫）＋ 暗紫遮罩，
  所以「远处看不清」是真的由渲染管线产生的，不是盖一层图假装

### 几处容易踩坑的实现细节

- **鼠标输入按帧合并**：`mousemove` 只累积位移，主循环里统一应用一次。
  直接在事件里转相机会导致同一帧多次转动，掉帧时表现为视角瞬移。
  同时丢弃超过 1500 count 的异常位移（驱动尖峰），避免视角突然甩飞。
- **累积值必须有单帧预算**：只合并不设上限会更糟 —— 掉帧时一帧能攒下几十个事件，
  一次性转出上百度，正是「视角突然跳走 / 被拉回正」的成因。
  现在单帧预算 800 count（sens 1.2 时约 67°），并按帧时长放宽最多 3 倍，
  保证低帧率下也不会把正常甩狙的输入吃掉。
- **CSS 滤镜只在值变化时写入**：每帧无条件设置 `canvas.style.filter` 会强制样式重算，
  全屏画布上是掉帧的主因之一。
- **暂停要做时间平移**：全局时钟 `T` 在暂停期间照常推进，而闪光和靶点记的都是绝对时间，
  恢复时必须把这段时长补回所有时间戳，否则飞行中的闪光会瞬间引爆。
- **致盲强度要用「起点 + 终点」表示，不能用「剩余 / 总时长」**：
  旧写法在第二发闪光叠加时把 `blindDur` 重设成剩余时长，于是 `blindAmount()` 又跳回 1.0，
  自动闪光模式下白屏被反复续满，射击长时间只出 MISS 音 —— 看起来就是"被闪之后左键不管用"。
  现在改成记录 `blindStart`，叠加时只外推 `blindUntil`，强度曲线单调衰减。
  同时把射击闸门从 `blind>0.12` 收紧到 `>0.35`，跟画面实际可见度对齐。
- **拖尾按固定采样率记录**（1/70 秒一个点），点数与帧率无关，高刷屏不会堆出上百个绘制点。
- **渐变改成离屏位图**：靶球、光晕、爆闪的 `createRadialGradient` 一次性预渲染成
  128×128 位图缓存，每帧只做 `drawImage`。原来每颗球每帧要新建两个渐变对象，
  9 颗球就是 18 个，是纯浪费。
- 帧率连续低于 45 时自动下调渲染精度（最多两档）；右上角可实时看 fps，
  也可以手动切「渲染画质」。
