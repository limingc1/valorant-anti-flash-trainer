## 第二轮修复（用户再反馈 4 点，37 项断言全过）

1. **视角瞬移（我上一轮引入的回归）**：把 clamp 从 `look()` 移到 mousemove 事件后，
   `applyLook()` 的**累积值没有上限**。掉帧时一帧攒几十个事件 → 一次转出上百度，
   表现正是「视角突然跳走/回正」。修法：单帧预算 `FRAME_MOVE_MAX=800`，
   超出按比例压缩，并按 `lastDt/0.0167` 放宽最多 3 倍（不吃掉低帧率下的正常甩狙）。
   教训：**输入按帧合并时必须同时设累积上限**，只合并是负优化。
2. **性能**：DPR 默认 2→1.0，新增画质档位 `QUAL_DPR=[0.75,1.0,2.0]`；
   靶球/光晕/爆闪的 radialGradient 改为 128×128 离屏位图缓存（spriteCache）后 drawImage
   （原来 9 颗球每帧新建 18 个渐变）；致盲全屏渐变按 W×H 缓存。
3. **蕾娜改 Nearsight**：`noPath:true`（凭空出现、无轨迹无拖尾）+ `spawn:0.5`（睁眼动画，
   未睁开不可击毁）+ `nearsight:true`（不是白屏）。近视由**渲染管线**产生：
   `surf()` 里 `fs*=1-0.38*fogNear; fe*=1-0.57*fogNear` 拉近雾线、雾色换 `FOG_NEAR` 暗紫，
   再叠 `drawNearsight()` 紫幕。必须击毁才解除，`dieAt`（6s）兜底消散。
   状态：`nearUntil/nearSrc/nearStart`，`fogNear` 每帧在 render 算一次供上百个 surf 复用。
4. 移除靶点存活时间与倒计时环（`cfg.lifetime` 及 UI 滑块全部删除）。

音效来源指引写在 `sfx/README.md`：FModel 解包本地客户端 .wem（vgmstream 转 wav）
或 OBS/系统录音 + 脚本切分。强调版权、不提供文件、仅个人使用。

## 第五轮（用户再反馈 4 点，88 项断言全过，主文件约 2010 行）

1. **「被抢鼠标」的真正根因找到了**：`requestPointerLock()` 没传
   `{unadjustedMovement:true}` —— Windows 指针加速一直在对 movement 做非线性加工，
   甩枪时位移被放大就是「像被抢一下」。已改为统一走 `relock()`（start/resume 都用它），
   不支持该选项的老浏览器 reject 后回退普通锁定。这等效 VALORANT 的 Raw Input Buffer。
   另外两个加固：`applyLook` 在 `lastDt>0.05`（卡顿帧/切回标签页）时**丢弃**累积位移；
   预算放宽上限从 3 倍收紧到 2 倍。
2. **准星改为 canvas 绘制**：删掉 `#cross` DOM 与 CSS，新增
   `CROSS_KINDS`（十字/点/圆/T字/无）与 `CROSS_COLORS`（5 色），
   `cfg.crossKind/crossColor/crossLen/crossThick/crossGap/crossDot`。
   两遍绘制：先半透明黑边再彩色（保证亮背景可见）；画在 render 最后（最上层）。
   注意：canvas 准星会被白屏的 CSS blur 一起糊掉 —— 行为上更真实，不算回归。
3. 靶球去掉外圈红色光晕：`BALL_S/BALL_R` 常量重构，绘制 `k=R/BALL_R` 按比例缩放。
4. **部署**：建了 `dist/`（index.html + sfx/README），用 CloudStudio 部署成功，
   链接 `https://66e587e7751b4693b9d10586ece6a764.app.workbuddy.link`。
   关键结论：**Cloudflare 在中国大陆访问不稳定**，国内访客推荐 EdgeOne Pages / 腾讯云 COS；
   DEPLOY.md 写了对比表和 Cloudflare（Git 连接 / wrangler）与 EdgeOne 的具体步骤。
   注意 dist 是快照，改源文件后要 `cp valorant-anti-flash-trainer.html dist/index.html` 重新部署。
