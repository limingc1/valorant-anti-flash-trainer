# music/ — 音乐盒曲目

音乐盒页签播放的曲目放这个文件夹。**音频随仓库入库**（和 `sfx/` 同策略）：
push 之后 Cloudflare Pages 自动部署，线上打开音乐盒就有歌，朋友零配置。

曲目来源：网易云音乐「雨沫云汐」的无畏契约大厅音乐系列，由仓库所有者收集。

## 用法

音频放进本文件夹，然后在 `manifest.json` 里按播放顺序登记文件名：

```json
[
  "01 大厅音乐.mp3",
  "02 拆弹时刻.flac"
]
```

刷新页面 → 菜单「音乐盒」→「重扫 music/」。

静态站点列不了目录，所以**必须**有 `manifest.json`。文件名要和磁盘上的**完全一致**
（含空格、括号），对不上那一首就不会出现在列表里。增删曲目后记得同步改它。

## 临时加歌（不进仓库）

音乐盒里「＋ 添加歌曲」可以导入本地文件，存在**你自己浏览器**的 IndexedDB 里，
不写进仓库。适合自己临时试听；换设备或分享给别人都不方便，长期曲子请放本文件夹。

## 注意

- 单曲上限 25MB、歌单上限 50 首（导入与文件夹同限）。
- 训练时闪光出手声会自动把音乐压低（音乐盒页可关），别担心听不到出手声。

## 为什么是入库的

2026-09-13 之前这里排除了全部内容，理由是「公开仓库 + push 即部署 = 再分发第三方音频」。
仓库所有者确认了曲目来源后决定改为入库（按个人练习项目定位处理）。

实际影响：仓库体积增加约 56MB，而且**永久留在 git 历史里** —— 以后删文件也删不掉，
除非重写历史。往这里加曲子前先掂量体积，单曲尽量压过再放。
